## 🌟 Overview

**Elite Cafe & Co.** is a modern, responsive, and editorial-grade website designed for a boutique specialty coffee house and kitchen. Built with clean, semantic Vanilla HTML, CSS, and JavaScript, it features a warm, inviting aesthetic with high attention to typography, spacing, and micro-interactions.

🌐 **Live URL:** [https://elite-cafe-and-co.vercel.app](https://elite-cafe-and-co.vercel.app)

---

## ✨ Features

- **🎨 Editorial & Warm Aesthetic:** Tailored palette featuring Warm Beige (`#F5F2EB`), Dark Olive (`#354238`), and Signature Rust Orange (`#FD4C1E`) with elegant Google Typography (*Playfair Display* & *Inter*).
- **📋 Interactive Menu Tabs:** Smooth tab switching between **Coffee**, **Food**, and **Desserts** with inline prices and instant category animations.
- **📅 Direct WhatsApp Table Booking:** Integrated reservation form that validates input and crafts an organized, pre-filled WhatsApp booking request directly to the cafe's management.
- **💬 Customer Reviews & Testimonials:** Editorial 3-column card layout highlighting real customer experiences.
- **📱 Mobile-First Experience:** Fully responsive layout with sliding mobile navigation drawer, floating WhatsApp action button, and a sticky mobile action bar.
- **⚡ Ultra Fast & Dependency-Free:** Zero bloat, no heavy frontend frameworks, instant page loads with high Lighthouse scores.

## 🚀 Getting Started

### Local Setup

To preview and work on this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nikhilverma29/Elite-cafe-and-co.git
   cd Elite-cafe-and-co
   ```

2. **Run locally:**
   - Double-click `index.html` to open directly in any browser, or
   - Use VS Code **Live Server** extension, or
   - Run a simple local server:
     ```bash
     # Using Python
     python -m http.server 3000

     # Using Node.js npx
     npx serve .
     ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
